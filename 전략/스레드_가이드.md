## 1. 계정의 진짜 목적
- 운영자: 폐기물 수집·운반 회사 대표(사업 10년+), 당근에서 사람 많이 만남, 2년 전부터 파이프라인 소득 시작.
- 운영 중: 당근 수익화 블로그 모임 「블로그로 용돈벌기(초보자환영)」(모임장 괴도루팡, **온·오프라인, 참가비 없음, 온라인은 줌(Zoom) 미팅으로 진행 중**) / 린치핀팀(암웨이 사업팀).
- **암웨이를 앞에 세우지 않는다.** 글의 목표는 읽는 사람이 스스로 "나도 수입원이 하나 더 있어야 하나?"를 떠올리게 하는 것.
- 흐름: 공감 → 수입원이 하나라는 자각 → 다른 수입원 가능성 → 블로그 모임(무료 입구)·DM → 관계 → 린치핀팀(DM에서, 사업 얘기할 땐 암웨이라고 투명하게).
- 모임 링크: https://daangn.com/kr/share/community/ref/invite-group/bdzAaYcfpPD

## 2. 수입원 생각 사다리 (글마다 한 칸만)
1. 자각: 수입이 하나라는 불안을 비유로 (다리 하나짜리 의자, 가팔라진 산길, 수도꼭지 하나)
2. 가능성: 수입원은 거창하지 않아도 된다 (용돈 정도, 글 하나, 시간 안 파는 것)
3. 방법: 같이 하면 꾸준해진다 → 블로그 모임
4. 사람·린치핀팀: 글에선 안 다룬다. DM에서.

## 4. 길이·구조
- **5~6문단, 문단당 1~3줄, 본문 100~170자 내외(공백 제외).** 이보다 길면 줄인다. 사용자가 "너무 길다"고 했음.
- 구조: ①장면·비유·명사 한마디 1줄 → ②속마음(따옴표 혼잣말 추천) → ③"스친이 탓이 아니야." + 구조적 이유 한 줄 → ④작은 전환 ("~면 ~해져", 설교 금지) → ⑤1초 답변 질문 + 이모지 1개 → (⑥CTA는 5번 규칙)
- 독자 호칭은 "너" 대신 **"스친이/스친이들"**. 편들기는 반드시 **"스친이 탓이 아니야"** (사용자 지정 표현).
- "~해야 해" 같은 설교 금지.

## 6. 타겟 (일(day) % 3)
- 0 → 영유아 키우는 아이엄마 (아이 재운 밤, 육퇴)
- 1 → 부업에 관심 있는 직장인 (퇴근길, 씻고 누운 밤, 내일 출근)
- 2 → 린치핀 철학에 끌리는 사람 (대체 불가능한 사람, "오늘 뭘 남겼지")
- 요일 감정 살리기 (금요일 밤, 일요일 밤 등). 시기 이슈(월말·연말·월급날·연말정산·명절) 적극 활용.

## 7. 사실·금지 규칙
- 반말. "린치핀팀" 최대 1번(공감만 날은 안 쓰는 게 좋음). **"암웨이" 절대 쓰지 않는다.**
- 판매·수익 보장·"월 OO만원" 같은 수입 숫자·과장 금지.
- 운영자 감정·경험·특정인 일화를 지어내지 않는다 ("나도 그랬어" 금지 → "그런 사람 진짜 많아"). 운영자가 엄마/직장인인 척 하지 않는다.
- 실존 인물 발언은 WebSearch로 확인된 것만, 출처 명시.
- 뉴스 수치는 검색으로 확인된 것만.

## 8. 카드 (automation/make_card.py)
```
python3.13 automation/make_card.py "<headline>" "<body>" out.png "블랙스톤 · @blk_writer"
```
- headline: 골드 명언 (12~22자, '|'로 2줄)
- body: 대구 4~5줄. '|'=줄바꿈, '||'=문단, 한 줄 18자 이하. **`*핵심 구절*`로 감싸면 골드 하이라이트** — 문단마다 핵심 한 구절만. **뒤에 붙는 조사(을·를·도·은·는 등)까지 하이라이트 안에 넣는다** (사용자 지정: `*길을 하나 더 내는 것도*`).
- 4번째 인자(선택)는 하단 작은 회색 글씨. 기본 "블랙스톤 · @blk_writer". 명사 인용 카드면 "출처 tvN 〈유 퀴즈 온 더 블럭〉 366회" 식.
- 예: `"길이 가팔라졌을 뿐이야." "여기밖에 못 왔다고|*스스로를 탓하지 마.*||가파른 산에선|*길을 하나 더 내는 것도*|오르는 방법이다."`
