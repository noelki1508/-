## 1. 블로그 정체성

| 항목 | 내용 |
|------|------|
| 블로그명 | 블랙스톤 (Blackstone) |

## 2. 카테고리 구조 (네이버 블로그 설정 기준)

```
블랙스톤
├── 언어와 글쓰기       ← 블로그 핵심 테마, 차별화 포인트
├── 독서 기록           ← 책 리뷰 + 핵심 구절 정리
├── 마인드셋            ← 자기계발, 생각 정리, 철학적 에세이
└── 일상                ← 가벼운 일상 기록, 독자와 친밀감 형성
```

## 3. 포스팅 전략

### 주간 목표: 주 3회 포스팅

| 요일 | 카테고리 | 예시 주제 |
|------|----------|-----------|
| 월요일 | 마인드셋 | 이번 주를 시작하는 생각, 자기계발 인사이트 |
| 수요일 | 언어와 글쓰기 / 독서 | 책 리뷰, 글쓰기 팁, 언어 이야기 |
| 금요일 | 일상 에세이 | 한 주 돌아보기, 발견한 것들 |

### 포스팅 공식 (네이버 노출 최적화)

1. **제목**: 키워드 + 감성/궁금증 유발 (30자 내외)
   - 좋은 예: `"매일 글을 쓰면 생기는 일 — 6개월 후의 변화"`
   - 나쁜 예: `"오늘 일기"`

2. **본문 길이**: 최소 1,500자 이상 (애드포스트 수익화에 유리)

3. **이미지**: 포스트당 3~5장 (본문 내용과 연관된 이미지)

4. **태그**: 포스트당 10~15개 (주제 관련 + 검색 많은 키워드)
   - 예: #독서 #책추천 #자기계발 #글쓰기 #에세이 #마인드셋 #성장

5. **마무리 문장**: 독자에게 질문을 던지거나 다음 글 예고

## 4. 네이버 SEO 핵심 원칙

- **제목에 핵심 키워드 반드시 포함** (네이버 검색 알고리즘 핵심)
- **소제목(H태그) 적극 활용**: 글 구조를 명확하게
- **첫 문단에 키워드 자연스럽게 삽입**
- **내부 링크**: 이전 글과 연결해서 체류 시간 늘리기
- **꾸준함**: 최소 3개월간 주 3회 유지 → 네이버 알고리즘 신뢰 확보

## 5. 애드포스트 수익화 로드맵

| 단계 | 목표 | 예상 기간 |
|------|------|-----------|
| 1단계 | 포스트 30개 달성, 이웃 100명 | 2개월 |
| 2단계 | 포스트 50개 달성, 일방문자 100명+ | 3~4개월 |
| 3단계 | 애드포스트 신청 (50개 이상 조건 충족) | 4~5개월 |
| 4단계 | 인기 키워드 포스트로 수익 최적화 | 6개월+ |

> 팁: 네이버 애드포스트는 **발행 글 50개 이상, 최근 90일 내 활동**이 기본 조건

## 6. 개인 브랜딩 전략

"블랙스톤"이라는 이름처럼 **단단하고 묵직한 통찰**을 주는 블로그로 포지셔닝

- **시그니처 문장 만들기**: 매 글 마지막에 고정 문구 추가
  - 예: `"당신의 언어가 당신의 세계를 만듭니다. — 블랙스톤"`
- **프로필 강화**: 블로그 소개란에 핵심 가치와 무엇을 다루는 블로그인지 명확히
- **이웃 맺기**: 비슷한 주제의 블로거와 적극적으로 이웃 교류
- **댓글 관리**: 달린 댓글에 반드시 답글 → 독자 충성도 상승

## 7. 월별 콘텐츠 계획 (처음 3개월)

### 1개월차 — 기초 쌓기 (12포스트)
- 블로그 소개 글 1편
- 자기계발/마인드셋 4편
- 독서 기록 3편
- 언어와 글쓰기 3편
- 일상 에세이 1편

### 2개월차 — 확장 (12포스트)
- 시리즈 기획: "책이 바꾼 나의 언어" 시리즈 시작
- 검색량 높은 키워드 포스트 위주

### 3개월차 — 최적화 (12포스트)
- 방문자 수 분석 후 인기 카테고리 강화
- 애드포스트 신청 준비
