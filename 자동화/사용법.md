# 네이버 블로그 임시저장 자동화

포스트 파일을 읽어서 네이버 블로그 글쓰기 화면에 **제목과 본문을 입력하고 '저장'(임시저장)** 버튼까지 눌러 줘요.
발행은 하지 않아요. 임시저장된 글에 사진을 넣고 카테고리를 고른 뒤 직접 발행하세요.

## 처음 한 번만: 설치

1. [python.org](https://www.python.org/downloads/)에서 파이썬을 설치하세요.
   설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**해 주세요.
2. 이 `자동화` 폴더의 **`install.bat`** 을 더블클릭하세요.
3. 컴퓨터에 크롬이나 엣지가 있으면 그 브라우저를 사용해요. 둘 다 없으면 명령 프롬프트에서
   `python -m playwright install chromium` 을 한 번 실행해 주세요.

맥이라면 터미널에서 이렇게 하세요.

```
cd 자동화
python3 -m pip install -r requirements.txt
python3 naver_draft.py
```

## 실행

- **`run.bat` 더블클릭** → `포스트` 폴더의 글을 전부 임시저장해요.
- 처음 실행하면 브라우저가 열리고 네이버 로그인 화면이 나와요. 직접 로그인해 주세요.
  **'로그인 상태 유지'를 체크**하면 다음부터는 로그인 없이 바로 진행돼요.
- 다 끝나면 결과가 나와요. 브라우저에서 확인한 뒤 엔터를 누르면 창이 닫혀요.
- 한 번 임시저장한 파일은 `저장기록.txt`에 기록돼요. 다음 실행 때는 그 파일을 건너뛰어요.

### 특정 파일만 저장하거나 옵션을 쓰려면

명령 프롬프트에서 `자동화` 폴더로 이동한 뒤 이렇게 실행하세요.

| 명령 | 하는 일 |
|------|---------|
| `python naver_draft.py` | `포스트` 폴더 전체 |
| `python naver_draft.py ..\암웨이_블로그_초안.txt` | 지정한 파일만 |
| `python naver_draft.py --dry-run` | 네이버에 넣지 않고 제목, 태그, 글자수만 확인 |
| `python naver_draft.py --force` | 이미 저장한 파일도 다시 저장 |
| `python naver_draft.py --plain` | 굵은 글씨 없이 입력 |
| `python naver_draft.py --no-tags` | 본문 끝에 해시태그를 넣지 않음 |
| `python naver_draft.py --blog-id 내아이디` | 글쓰기 화면이 안 열릴 때 블로그 아이디를 직접 지정 |

## 포스트 파일 형식

**마크다운 (.md)**: `포스트` 폴더의 기존 글 형식이에요.

```
# 제목

**카테고리**: 마인드셋
**추천 태그**: #태그1 #태그2

---

본문 ... (## 소제목, **굵게** 는 굵은 글씨로 들어가요)
```

**메모장 (.txt)**: 메모장으로 바로 쓸 수 있는 형식이에요.

```
[제목]
글 제목

[본문]
본문 내용...

[해시태그]
#태그1 #태그2
```

- 태그는 본문 맨 아래에 해시태그로 들어가요. 본문의 해시태그는 발행할 때 태그로 등록돼요.
- `[사진 1 - ...]` 같은 줄은 글자 그대로 들어가요. 그 자리에 사진을 넣고 해당 줄을 지우면 돼요.

## 주의할 점

- **`naver_profile` 폴더에는 네이버 로그인 정보가 들어 있어요.** 다른 사람에게 주거나 업로드하지 마세요.
  이 폴더는 `.gitignore`에 들어 있어서 깃에도 올라가지 않아요.
- 글쓰기 화면에 "작성 중인 글이 있습니다" 팝업이 뜨면 자동으로 **취소**를 눌러 새 글로 시작해요.
  네이버에서 쓰던 글이 있다면 실행하기 전에 먼저 저장해 두세요.
- 네이버가 글쓰기 화면을 바꾸면 버튼을 못 찾을 수 있어요. 그럴 때는 `naver_draft.py` 위쪽의
  `SEL_...` 값만 고치면 돼요.
- 너무 많은 글을 한꺼번에 반복해서 올리면 네이버가 비정상 활동으로 볼 수 있어요. 적당히 나눠서 쓰세요.
